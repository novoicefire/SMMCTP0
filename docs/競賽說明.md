### C. Reminders of Webpage Project (網頁製作注意事項)

- **a.** 網頁內容須**包含小組成員介紹、公司介紹（歷史與組織架構-事業與功能層級單位等、財務資訊）、市場分析、資源評價、成長策略**。可參考 TP0-3，選擇適合的分析工具完成個案公司之分析。
- **b.** 若有餘裕，可使用 104 人力銀行搜尋個案公司之職缺資料，列出職位名稱、所需技能及薪資福利等。
- **c.** 設計一個具備完整結構的互動網頁，功能須涵蓋：**中英雙語切換、明暗模式設定、語音導覽、互動問答（小測驗）以及翻轉字卡**。在導覽設計部分，運用首頁跳轉功能提升網頁易用性。網頁必須**採用響應式網頁設計( Responsive Web Design, RWD)**，讓使用者在任何裝置皆能順暢地瀏覽。網頁介面底部需放上課程名稱與授課教師姓名。
- **d.** 語音導覽裝置須預設：EN＝British-Male；繁＝Taiwan-Yating。
- **e.** 可加入圖片或影片以提升網頁豐富度，但網頁的任何圖片或影片不能顯示錯誤。
- **f.** 網頁須部署於 GitHub Pages 等平台，未完成佈署之組別將酌予扣分。
- **g.** 小組全員應共同負責網頁整體的品質與一致性，而非透過分工方式切割任務。請於網頁新增簡短說明區塊，說明組員如何協作、整合並共同完成專案，而非列出各自負責項目。
- **h.** 網頁應保持清晰、順暢及美觀。整體內容須以中英文雙語呈現，其他語言為選配。內容不宜過長，應善用視覺與互動設計，以更有效率地傳達重點。
- **i.** 所有外部資料與 AI 生成內容皆須符合學術誠信與教育合理使用原則。請主動揭露專案中使用 AI 工具之部分，例如撰文協助、逐字稿處理或網頁設計生成等，並適當註明所使用之工具與版權來源。
