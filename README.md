# 從 DRAM 景氣循環到 AI 記憶體：南亞科技策略分析

### From DRAM Cycles to AI Memory: A Strategic Analysis of Nanya Technology

本專案為 **1142 國際策略管理－期末互動式學習網頁競賽** 之參賽作品。我們以全球第四大 DRAM 廠商——**南亞科技股份有限公司 (Nanya Technology Corporation)** 為研究對象，深入探討其在 DRAM 景氣循環、製程技術升級、AI 伺服器需求爆發以及全球客戶策略投資下的定位與成長策略。

本網站採用單頁式網頁設計 (One-page Website) 並融合 **Cohere 風格的極簡科技美學**，將複雜的策略管理分析轉化為具備高度互動性、資料視覺化與卓越使用者體驗的學習平台。

## 📊 策略分析板塊與內容亮點

網站內容非單純的文字堆疊，而是將 TP0–3 的分析工具融入視覺化區塊：

1. **公司概覽與歷史時間軸**：介紹南亞科技作為全球第四大 DRAM 廠的定位，以時間軸呈現技術遷移與關鍵里程碑。
2. **組織架構與全球據點**：透過互動式卡片，展示其在美洲、歐洲、日韓、中國與台灣總部的銷售、行銷與技術支援分工。
3. **企業願景、使命與價值**：以翻轉卡片展示「智慧世代最佳記憶體夥伴」之願景與創新、誠信、當責、效率的核心價值。
4. **財務績效視覺化**：繪製 2021–2025 年的營收與 EPS 走勢，解讀 DRAM 景氣循環以及 2025 年第四季受惠於 ASP 回升與 AI 需求重新轉盈的策略意義。
5. **DRAM 市場分析 (SWOT / PESTEL)**：分析 Samsung、SK hynix、Micron 與南亞科的競爭態勢，探討 AI 伺服器與 RDIMM 對成熟製程市場的外溢效應。
6. **關鍵資源評價 (VRIN 分析)**：評估南亞科自主研發能力、全球客戶網絡、產能擴建及 2026 年獲 Solidigm、SanDisk 等大廠私募入股之策略投資關係，確認其持續性競爭優勢。
7. **三層成長策略路徑**：
   - _短期_：把握 DRAM 價格上升週期與毛利率改善。
   - _中期_：提升 DDR5、LPDDR5 與 AI 相關高階產品比重。
   - _長期_：推進 10 奈米級製程、新廠產能開出與客戶長期合約綁定。
8. **104 職缺洞察**：延伸整理南亞科關鍵職務（軟體開發、FAE 技術工程師、製程開發工程師）之工作職責、必備技能與薪資福利，連結學生職涯規劃。

## 🎨 互動式學習網頁設計規範（Cohere-Inspired Standard）

本網站的視覺與互動設計遵循 [Design System Analysis: Cohere](https://getdesign.md/cohere/design-md) 規範，呈現高級且具科技感的介面：

- **調色盤**：
  - **光亮模式**：以 Canvas White (`#fefefe`) 與沙礫色 (`#c6b7a2`) 作為主色，搭配深綠 (`#003c33`) 標題與深藍黑 (`#020617`) 內文。
  - **暗黑模式**：以 Cohere Black (`#000000`)、深綠 (`#003c33`) 與深藍黑 (`#020617`) 作為主色，強調色使用電光藍 (`#1863dc`) 與溫暖珊瑚橘 (`#ff7759`)，展現半導體晶片線路的科技質感。
- **排版**：display 標題使用緊湊字距與行高，營造學術研究室與科技巨頭的精煉氣質。
- **微動畫**：按鈕、翻轉字卡、測驗選項皆具備平滑過渡動畫，點擊與懸停反饋靈敏，視覺體驗極為流暢。

## 🚀 本地執行與部署

### 1. 本地開發與瀏覽

由於本專案為純前端網頁（HTML5、CSS3、Vanilla JS），您可以直接使用瀏覽器開啟 `index.html` 進行瀏覽。

若要體驗最流暢的開發與載入環境，建議使用 VS Code 的 **Live Server** 擴充功能，或在專案根目錄下啟動一個簡易本地伺服器：

```bash
# 使用 Python 啟動簡易伺服器
python -m http.server 8000
```

接著在瀏覽器中輸入 `http://localhost:8000` 即可。

### 2. 語音導覽測試注意事項

- 請使用 Chrome 或 Edge 瀏覽器以獲得完整的 `Web Speech API` 支援。
- 點擊語音導覽按鈕時，系統會自動匹配您系統中的語音庫（英文優先匹配 British-Male 聲線，中文優先匹配 Taiwan-Yating 聲線）。

### 3. 部署 GitHub Pages

本專案已設定完畢，只需將代碼推送至 GitHub 倉庫的 `main` 分支，並於倉庫設定中開啟 GitHub Pages，即可自動完成部署。
